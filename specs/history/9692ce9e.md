# Commit 9692ce9e

- **Date:** 2026-09-12T23:10:24+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** Resolve the mermaid renderer at runtime, and add `specky setup-diagrams`

Diagram rendering broke for pip-installed specky because npm dependencies lived in gitignored `node_modules` and weren't shipped in wheels. New `mermaid_tool.py` resolves renderer path at runtime (`$SPECKY_MERMAID_DIR` → `~/.cache/specky/mermaid-render` → vendored copy), so installed specky finds dependencies in user's cache dir (persists across upgrades). New `specky setup-diagrams` command populates cache and reports failures loudly; silent degradation removed so users notice when setup's needed. Docs + doctor script updated to reference new command and resolved paths.

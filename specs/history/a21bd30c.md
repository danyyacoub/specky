# Commit a21bd30c

- **Date:** 2026-09-21T13:25:32+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** feat(viewer): trim sidebar titles, add type icons and color accents

This commit refines the generated-docs viewer's visual language. Sidebar links now drop the redundant "<Module> —" prefix that repeated each group header (keeping the full title as a hover tooltip), and both sidebar links and search hits show the feature/workflow icon tinted to match that type's chip color, so doc type reads at a glance. The titlebar and sidebar get a new accent-tinted "chrome" background (with dark-mode variants and dedicated hover/active states, since the old surface tokens disappeared against the tint), and each doc page now carries a `data-type` attribute that drives a per-type accent — indigo for features, amber for workflows, default accent otherwise — applied to section-heading bars, table headers, and blockquotes, making a doc's type consistent from chip to sidebar to page body.

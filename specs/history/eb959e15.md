- **Message:** Search whole doc bodies in the viewer, exactly when served

Viewer search now indexes whole doc bodies offline + serves full-text over HTTP. Offline search gets truncated bodies (400–8K chars per doc, budgeted by doc count) so repos with thousands of commits don't ship megabytes of text on every page load; served pages instead ask `/search?q=` and get ranked results from the real index. Fixed two bugs: served pages were calling the wrong API port (now auto-detected via origin fallback), and markdown stripping ate underscores from identifiers like `busy_timeout`. Docs updated to reflect new `/search` endpoint, access rules, and payload bounds.

# Specky can now use the Devin CLI as its AI provider

- **Date:** 2026-09-24T11:03:11+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** feat(ai): add devin cli as an agent provider

## What changed

`specky init --provider agent --agent devin` is now a valid configuration, alongside Claude Code, Codex, Gemini CLI, opencode, Kiro and Cursor Agent. Devin runs headless in print mode with the prompt piped in, on its default model or one named with `--model`. The setup skill also documents installing the Devin CLI in a Devin VM blueprint and restoring its credentials from a secret.

## Why

`devin -p` ignores stdin, so the prompt must be passed with `--prompt-file /dev/stdin`, and `--respect-workspace-trust false` keeps print mode working in a fresh clone or a Devin VM where the workspace-trust prompt can't be answered.

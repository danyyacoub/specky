# Devin Desktop commits now hand off to the document-commits skill

- **Date:** 2026-09-24T12:07:15+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** feat(ai): hand devin desktop commits off to the skills

## What changed

Commits made inside a Devin Desktop session, with `provider = "agent"` and `agent = "devin"`, are now handed off to the document-commits skill instead of being documented by a headless run. `specky doctor` now only warns, rather than fails, when the Devin CLI is logged out inside a Devin Desktop session.

## Why

Devin sets no session marker of its own, but Desktop shells inherit a VSCODE_IPC_HOOK pointing into the app's data directory, so that path identifies the session; session markers can now match on a substring too. Inside a Devin session those commits never run `devin -p`, so the CLI login only matters for terminal and CI commits.

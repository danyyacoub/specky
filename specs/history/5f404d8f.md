# Commit 5f404d8f

- **Date:** 2026-09-21T20:00:55+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** feat: switch mention trigger to @ and add launch-viewer skill

This commit switches the chat mention trigger from `#` to `@`, since `@` is the familiar mention key while `#` reads more like a heading or tag. Scope tokens become `@module:<name>` / `@feature:<slug>`, and the picker now only opens on an `@` at the start of a word so typing an email address mid-sentence doesn't hijack Enter. It also adds a new `launch-viewer` skill that rebuilds the site (`index` + `render-html`) and serves it: in the Claude desktop app via a `specky-serve` entry in `.claude/launch.json` (so the pane shows the server), and in a terminal as a background `specky serve` with the browser opened to it. The README and MODULES docs were updated to describe the new skill.

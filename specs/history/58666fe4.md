# specky sync --commit lands a run's docs as one commit

- **Date:** 2026-09-24T18:07:49+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** feat(cli): add sync --commit to land a run as one doc commit

## What changed

Running `specky sync --commit` now commits the docs it wrote as a single `docs: sync specky docs` commit, staging only the files that run touched plus `MODULES.md` when it changed. Plain `specky sync` still leaves the docs in the working tree uncommitted for you to review.

## Why

With the git hooks off, a developer wants to document a shared branch periodically and have the result committed the same way a hook fire commits it — one doc commit per run instead of one per commit.

# Cross-doc link documentation corrected for viewer and answers

- **Date:** 2026-09-22T10:11:19+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** docs(rendering): correct cross-doc-links scope [skip specky]

## What changed

The cross-doc-links spec now states that heading ids and link resolution run after body rendering in both the viewer and `specky export`, not just export. It also clarifies that answer links which aren't `.md` paths (page names or in-page anchors) are kept as written and still vetted by the sanitizer.

## Why

The previous spec described the post-rendering step and non-doc-link handling as export-only, which no longer matched how the viewer and Spec Assistant answers behave.

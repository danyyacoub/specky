# Deployed servers can set their AI provider and models from environment variables

- **Date:** 2026-09-23T19:31:19+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** feat(chat): let SPECKY_AI_* env vars set the provider and models

## What changed

A deployed Spec Assistant can now be configured entirely through SPECKY_AI_* environment variables, so a container needs no specky.toml. SPECKY_AI_<KEY> overrides a single key of the [ai] table, while setting SPECKY_AI_PROVIDER replaces the whole table instead of patching it; specky doctor names the variables in effect.

## Why

A container built from the repo has no specky.toml since it is gitignored, and a deployed server usually wants different models than a laptop. Putting the config in the host environment matches how SPECKY_AUTH_* already works, and replacing the whole table keeps a local agent or model name from leaking into the server's provider config.

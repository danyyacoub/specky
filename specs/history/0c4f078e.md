Prevent doc hook from overwriting hand-written content. Problem: `sync_feature_doc` regenerated entire doc bodies unconditionally, destroying hand-written sections twice (check.md and doctor.md). Three gates now protect against this: `lost_content` measures preservation per-section with MIN_KEPT_RATIO (destructive rewrites ran 46-71% vs. honest updates at 98%+); `update_feature_doc` requests JSON sections instead of whole body, leaving unmapped sections byte-identical; `authored: human` freezes docs outright. Refused regenerations go to `.specky/pending/` (gitignored) instead of disk. Restores both damaged docs (check.md merged with correct semantics added after damage; doctor.md and feature-sync.md rewritten), marks all four `authored: human`. Also fixes export.py docstring and local-rag-server.md's hardcoded port ignoring `--port` flag.

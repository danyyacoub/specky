# Commit a12c1f43

- **Date:** 2026-09-15T17:55:02+02:00

- **Message:** fix: ground chat answers in whole docs, and rank on topic not phrasing

Chat RAG was broken two ways: answer came from 40-token excerpts around search hits (too small to actually ground an answer), and ranking used question words instead of topic. Now: index decides *which* docs matter, those docs sent whole (not excerpts) within budget (24k cap per doc, 60k total), question words dropped before search, and doc name/title/tags weighted above body content. Truncation and excerpting are now labelled in context so model sees what it's working with. Real-world test: "how is payment implemented" now retrieves full payment-settlement doc instead of ranking it ninth behind MODULES and GLOSSARY.

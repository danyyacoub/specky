# Documents with YAML block-list sources keep their type and tags

- **Date:** 2026-09-24T11:27:50+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** fix(frontmatter): read yaml block lists

## What changed

Previously, a document whose sources field was written as a YAML block list (a sources: line followed by indented - path lines) had its entire frontmatter dropped, so its type and tags disappeared from the catalog and re-tagging added a second block. Now block lists are read as a list of values, quoted items are unquoted, a bare key: with no items is left as an empty string, and a list item with no key above it is not treated as frontmatter.

## Why

Agents write list values as block lists as often as inline form, and a block the parser could not read lost the document's whole frontmatter.

# Codex users can now set up specky with documented steps

- **Date:** 2026-09-22T18:04:50+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** docs: add codex setup to the readme and agents guide

## What changed

The README now lists Codex alongside the other supported agents and adds a Codex section with setup steps: adding the specky MCP server to .codex/config.toml, copying the find-feature, explore-docs and document-domain skills into .agents/skills/, and optionally adding the specky-lookup subagent in .codex/agents. The AGENTS.md intro also mentions Codex as a reader of that file.

## Why

Codex has no plugin, so the docs explain how to connect specky to it by hand.

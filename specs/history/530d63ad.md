# README rewritten to explain specky's features, not every CLI flag

- **Date:** 2026-09-22T12:18:34+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** docs: rewrite the README to be brief, with a features section

## What changed

The README was cut from a full CLI and configuration reference to a short overview: what specky does, how it works, and how to install and set it up, with a new Features section (Docs that follow your commits, document on demand, searchable docs site, Spec Assistant, CI doc-drift gate, agent-readable docs). It now points readers to `specky --help` and the full docs for command details and flags. Architecture notes moved into CLAUDE.md, the distribution no longer ships /assets, and Devin's integration guide links to the CI check section instead of a README anchor that no longer exists.

## Why

The README had duplicated the specs/ documentation and grown into a reference; the rewrite keeps it brief and aimed at new users, while keeping contributor architecture notes where contributors look.

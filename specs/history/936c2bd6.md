# Add a /commit workflow that reviews changes and writes conventional commits

- **Date:** 2026-09-22T12:26:59+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** add commit + generator test

## What changed

A new /commit command is available: it inspects staged or unstaged changes, runs inline checks for debug code, leftover TODOs and secrets, then spawns parallel review subagents for performance, code quality and regressions before proposing a conventional commit message and committing after confirmation. It also reminds you to run /add-tests and /document afterwards.

## Why

Review staged/unstaged changes, run targeted review subagents, then generate a conventional commit.

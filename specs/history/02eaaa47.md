# Specky now tells host models to check the docs before the source code

- **Date:** 2026-09-21T22:04:19+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** feat(mcp): point host models at the docs first, with an explore-docs skill

## What changed

The specky MCP server now sends guidance when a host model connects: answer what-a-feature-does, how-a-flow-works and why-it-changed questions from the docs first, cite the doc, and verify against its sources before changing code on the doc's word. A new explore-docs skill covers the same lookup (search, read, behaviour ids, history, sources check) and is documented in the README and the Kiro and opencode integration notes.

## Why

Hosts that defer MCP tools (such as Claude Code) only show the model tool names, so nothing signalled that a behaviour question has a cheaper, citable answer in the docs than a read through the source.

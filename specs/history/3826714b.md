# specky ships as a public plugin and PyPI package, staying quiet in repos that don't use it

- **Date:** 2026-09-22T10:42:03+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** feat: prepare specky for public release as a plugin and PyPI package

## What changed

Installing the specky plugin no longer affects repos without documentation: the post-commit hook, MCP instructions and indexing only run where specky.toml exists, and .specky/ no longer shows up as untracked. Users can install from PyPI or the Claude Code marketplace, run /specky:setup to configure a project, and check the installed version with `specky --version`.

## Why

The plugin is enabled per user, so its hook and MCP server previously ran in every repo, causing config errors after each commit, leftover .specky/ directories and 'check specky first' instructions in projects that never chose specky.

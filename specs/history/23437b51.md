- **Message:** Escape the two characters that break a mermaid node label

Fix mermaid node labels truncating on `]` character. Titles like `Billing [v2] (draft)` were rendering as `"Billing [v2` with tail lost and stray quote added. New `_mermaid_label()` escapes `]` and `"` to entity codes — only these two break in mermaid within quoted labels. Other specials `(){}|<>#` survive unchanged. Added two tests: one for escape logic, one through actual renderer to catch regression.

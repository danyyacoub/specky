- **Message:** Add `specky pr-comment`: what a range did to the docs, as markdown

**New PR comment tool prints what docs changed, not just that they changed.** `specky pr-comment` generates markdown summaries of doc changes across a range — shows added/updated/removed docs with their one-line purposes from MODULES.md, plus diffs of `## What It Does` sections so reviewers see product behavior shifts without opening each file. Output bounded to fit GitHub's comment limit: history docs counted rather than listed, lists capped at 30 items, only 10 docs detailed with diffs, body trimmed at 65k chars. Never posts (side effect is user's pipe to `gh pr comment`). Made two helpers public (`generator.modules_purposes`, `testgen.section`) to avoid duplication.

# specky init can now configure your existing coding agent instead of an API key

- **Date:** 2026-09-23T18:57:07+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** feat(cli): configure specky on the current coding agent or an openai-compatible api

## What changed

Running `specky init` now offers to set up specky on the coding agent you already have installed (Claude Code, Codex, Gemini CLI, opencode, Kiro, Cursor Agent) using its headless mode and default model, with no API key needed; any OpenAI-compatible endpoint is still available as an alternative, and hand-written `specky.toml` files with `anthropic` or `command` providers keep working. A new `setup` skill lets agents like Codex, opencode, Kiro and Devin configure specky themselves, and `specky --help` and `specky doctor` now point at the setup commands.

## Why

Most people setting specky up already run a logged-in, paid-for coding agent, so reusing it avoids a separate API key and provider bill; the setup skill was no longer Claude Code-specific, so other agents can run setup on their own.

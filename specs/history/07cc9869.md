- **Message:** Add `specky export`: one-file HTML, PDF and Confluence output

`specky export` writes docs as single files for sharing. Default output is one no-JS HTML page (glossary as abbr hovers, not scripts) with table of contents and print stylesheet—survives email and printing from any browser. `--pdf` runs weasyprint for PDF when installed; if not, reports where single-page is and what to install (no hard dep on rendering engine). `--confluence` writes storage-format XHTML per doc plus index—unwraps table styling, drops glossary, keeps mermaid as source code macros. Reuses html_render pipeline so export matches viewer, not a second renderer's guess. `specs/history/` excluded by default (one doc per commit, grows with repo) but `--include-history` includes it; report always says what was left out and how big result is—nothing silent.

# Doc sync stops committing your staged MODULES.md edits

- **Date:** 2026-09-22T17:47:23+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** fix(history): stop the doc hook committing others' MODULES.md edits

## What changed

When specky's documentation hook runs, it now commits specs/MODULES.md only if that run actually changed the file, instead of staging it on every fire. Previously any edits a developer had already staged to MODULES.md were swept into the bot's `docs: sync specky docs [skip specky]` commit.

## Why

MODULES.md was staged on every fire whether or not the fire changed it, so a developer's pending index edits landed in a docs-sync commit under specky's marker.

# Doctor now fails when docs have diagrams but no renderer is installed

- **Date:** 2026-09-24T14:10:00+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** feat(doctor): fail when docs have diagrams and no mermaid renderer

## What changed

A missing diagram renderer is now reported as a failure (not a warning) whenever any doc contains a mermaid block, naming how many docs are affected and pointing at `specky setup-diagrams`; it stays a warning when no docs have diagrams yet. `specky doctor --json` moves the diagrams entry to the end of the report and the setup skill gains a step that installs the renderer when Node is present.

## Why

Without the renderer, diagrams render as source text and the write-time diagram check passes everything; as a warning it went unread for weeks on a real repo, so both problems went unnoticed in an otherwise green report.

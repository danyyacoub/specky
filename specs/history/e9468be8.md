# Commit e9468be8

- **Date:** 2026-09-12T22:59:15+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** Match history docs on the full sha, and add sync --all-branches

Fixes silent doc loss from two sources: 8-hex filename collisions (rare on small repos, unavoidable at scale) and side-branch commits never getting considered. History docs now record their full SHA in frontmatter; when two commits collide on the 8-hex prefix, newer one gets `<sha12>.md` while existing doc stays intact. Added `--all-branches` flag to walk every ref instead of just HEAD, catching side-branch work. Matching costs O(commits considered) by reading the recorded SHA; pre-existing docs without that field fall back to filename matching.

# Commit 4ebb5b66

- **Date:** 2026-09-21T12:03:50+02:00

- **Message:** feat(viewer): widen the doc column and open diagrams full screen

The document column was widened from 760px to 1040px to use desktop windows better: at 760px the text had only 664px, leaving most of the window empty.

A "Full screen" button is now added to every diagram, opening it alone in a new tab fitted to the window with wheel zoom, drag-to-pan, and double-click to refit. This lets a wide flowchart be read whole instead of as a horizontally scrolled strip. The new tab is built as a Blob URL from the SVG already inline on the page, so no extra files are needed per diagram and it works from `file://` as well as under `specky serve`. The button appears on hover but stays reachable via keyboard focus, and the new `DIAGRAM_JS` block is appended to the single shared script scope, where it relies on existing helpers like `escapeHtml` and is also invoked when chat answers add diagrams.

# Skill model selection docs now say the setting is per machine, not per repo

- **Date:** 2026-09-22T17:55:54+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** docs: fix two slips in the skill model selection doc

## What changed

The skill model selection doc previously said a repo sets `[skills] model` in `specky.toml`; it now says each developer sets it in their own gitignored `specky.toml`, so the choice is per machine. The host-compatibility table row was also corrected to state that on Codex, opencode and Kiro the per-host agent or command pins one of that host's models, `[skills] model` doesn't apply, and no skill frontmatter carries a `model` key.

## Why

The commit corrects two slips in the skill model selection documentation.

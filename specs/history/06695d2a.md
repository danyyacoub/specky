# Answer tables wrap between words and scroll sideways when too wide

- **Date:** 2026-09-22T15:16:48+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** fix(chat): stop answer tables from splitting words mid-word

## What changed

Previously, cells in a table inside a Spec Assistant answer could break mid-word, so short labels like "Resolve range" were squeezed into "Resolv / e range". Now table cells wrap only between whole words, and a table wider than the panel scrolls sideways within its frame; long unbroken paths in ordinary prose still break so the panel never widens.

## Why

The .chat-msg rule's overflow-wrap: anywhere made every letter a break point when auto table layout measured column widths, splitting words inside answer tables. Tables now opt back into whole-word wrapping while prose keeps the stricter rule.

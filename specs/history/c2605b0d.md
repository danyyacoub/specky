# Commit history entries now show who changed what, on the home page and in search

- **Date:** 2026-09-22T11:39:24+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** feat(history): add structured docs and a home-page activity brief

## What changed

History docs are no longer a single paragraph under "Commit <sha8>"; each now carries a headline, an impact label (feature, improvement, fix, internal), What changed / Why sections, and a link to the feature doc it belongs to. The committed files are the source for search and feature-to-commit answers, so a fresh clone or CI run sees the same results. `specky sync --refresh-history` rewrites legacy one-paragraph docs in place, and the home page shows recent activity per person, with merged branches presented as one change told by their commits' docs and unmerged branches marked in progress. Agents and bots are excluded, and merge commits no longer get their own doc.

## Why

A product owner wants to see who changed what without reading commits, and summaries previously lived only in the gitignored index, so a fresh clone or CI run had neither a summary nor its feature link. This also completes the micro-doc change started in 3826714.

# Run each specky CLI workflow as a slash command in Claude Code

- **Date:** 2026-09-24T14:10:31+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** feat: add a plugin slash command for each cli workflow

## What changed

The plugin now ships slash commands such as /specky:doctor, /specky:check, /specky:lint, /specky:verify-migration, /specky:search and /specky:sync, one per CLI workflow. Each runs its command, explains the result, and asks before anything that costs AI calls, moves files or posts; opencode and Codex can copy them in. The release also adds specky lint, dropped-fact reporting, specky adopt --verify, a TAGS.md tag registry, new doc template sections and tag siblings in the viewer.

## Why

The commit gives no motivation beyond the feature itself: the plugin gains a slash command for each CLI workflow, sharing the skills namespace and checked by tests so commands don't collide with skills or call missing subcommands.

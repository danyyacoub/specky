- **Message:** feat(cli): replace bootstrap with `specky document`

Replaced `specky bootstrap` with `specky document "<feature>"` after the whole-repo bootstrap approach proved structurally shallow: a budget spanning an entire repo left each feature only a few kilobytes, and features the symbol index missed were never documented at all. The new command inverts that by documenting one named feature at a time, using a `Provider.converse` tool loop over an allowlist derived from `git ls-files` so the model searches the repo itself and scope stops being the constraint. Because depth requires trust, the write path keeps all existing guards and adds two: a doc backed by no file the model actually opened is refused, and generated mermaid is repaired when unambiguous and rejected when unparseable. Removing bootstrap also collapses its front-loaded setup—docs can now be added incrementally with no repo-wide pass.

# Specky's MCP docs tools now work in read-only and plan-mode agents

- **Date:** 2026-09-24T15:12:14+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** allow readonly

## What changed

Every tool the Specky MCP server exposes (ping, list_features, list_workflows, list_tags, get_graph, commit_info, commits_for_doc, list_domains, search_docs, read_doc, doc_behaviours, search_history, render_acceptance_table) is now declared read-only. Clients that gate tools by mode, such as plan mode or read-only agents, will no longer block them; previously they could be hidden or rejected despite only reading docs, the index or git.

## Why

The tools only read the docs tree, the index or git, so marking them as such lets mode-gating clients keep calling them.

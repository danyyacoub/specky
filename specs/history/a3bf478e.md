# Specky can now run Claude on Amazon Bedrock using existing AWS credentials

- **Date:** 2026-09-23T20:06:48+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** feat(cli): add a native amazon bedrock provider

## What changed

A new AI provider option, Bedrock, lets specky call Claude through an AWS account instead of an Anthropic API key. It is selected with `specky init --provider bedrock` or `SPECKY_AI_PROVIDER=bedrock`, plus optional AWS region and profile settings, and requires installing the CLI with the `specky[bedrock]` extra. Prompt caching and the tool loop work the same as the Anthropic provider; batch processing is not available. The README also gained a step-by-step guide for deploying the Spec Assistant server.

## Why

Teams already on AWS can use the Claude models and credentials they have, such as an IAM role on a server or a profile on a laptop, without an Anthropic key. The AWS SDK stays an optional extra so users who never touch AWS don't install it.

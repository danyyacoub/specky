# Specky now catches docs that lose facts, terms or tags

- **Date:** 2026-09-24T14:10:11+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** feat(cli): catch facts, terms and tags docs lose or drift on

## What changed

specky check now reports constants, formulas and precedence rules a doc stopped stating, and specky lint flags one-doc tags, glossary gaps and numbers that conflict with the doc owning them. A new specs/TAGS.md registry, Constants & Invariants and Maintainer Notes doc sections, and tag siblings in the viewer's Related block support the same goal, and the doc-writing skills instruct agents to run lint and reuse registered tags.

## Why

An agent-run migration kept every heading while dropping scoring weights, formulas and two dozen glossary terms, and shipped one-doc tags and conflicting rules.

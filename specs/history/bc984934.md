# Commit bc984934

- **Date:** 2026-09-18T14:52:54+02:00

- **Message:** feat(generator): give workflow docs their own shape

Workflow docs previously shared the feature-doc template, which buried their sequence—the key thing readers need—alongside branches under one heading, and only asked for a diagram on the `document` path, never the commit-driven one. They now get their own shape: a happy-path-only `## How It Works`, a mermaid diagram directly beneath it, and an `## Edge Cases` table for branches. The section name was kept deliberately because `lost_content` rejects regenerations that drop a section, so renaming would strand existing workflow docs with both. The viewer renders the happy path as a stepper, `specky check` flags a missing diagram or Edge Cases as non-failing advice, and the five other places restating the doc shape were updated to match.

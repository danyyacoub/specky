# Session agents now write their own commit docs instead of launching a second agent

- **Date:** 2026-09-24T11:44:21+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** feat(ai): let the session agent write its own docs through skills

## What changed

When provider is set to "agent", a commit made inside that agent's session no longer spawns a headless copy of the agent to write documentation; the hook instead reports the pending commits and points to a document-commits skill, which uses `specky pending --json` and `specky record-commit`. `specky document` now points at the document-domain skill (`--headless` restores the old behaviour), and `[ai] skill_handoff = false` opts out. Commits from a terminal or CI, API providers, and agents without a session marker are unchanged.

## Why

The headless copy started cold with no tool channel, so the agent that already had the repo in context now does the documentation itself.

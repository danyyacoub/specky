# Commit e0d7e533

- **Date:** 2026-09-15T15:35:19+02:00
- **Author:** dany <dany.yacoub@gmail.com>
- **Message:** fix: decode git output leniently so a non-UTF-8 file can't abort a run

Non-UTF-8 files (PDFs, CP1252-encoded source) in diffs killed the run with UnicodeDecodeError. git only omits binary with early NUL, so a PDF gets emitted as text in the diff. Now decode git output leniently with `errors="replace"` in _commit_info, pending_commits, gitlog.run, and check._git. Metadata-only calls stay strict. Added test with real PDF.

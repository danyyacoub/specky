# specky

A coding-agent plugin that generates and maintains functional documentation *in place*, indexes it and commit history in SQLite, and renders a searchable HTML viewer with an AI chat for non-technical stakeholders.

Works as a Claude Code plugin (first-class) and via a shared `SKILL.md` + MCP config with opencode and Kiro.

See [specs/PRODUCT.md](specs/PRODUCT.md), [specs/MODULES.md](specs/MODULES.md), and [specs/GLOSSARY.md](specs/GLOSSARY.md) for what this plugin is; see the plan for the phased build order.

## Status

Phase 2 done. Plugin manifest, `document-domain` skill, and a placeholder MCP server (`ping`) are in place (Phase 1). AI provider setup and automatic per-commit micro-docs are in place (Phase 2): `specky init` configures a provider (Anthropic, an OpenAI-compatible endpoint, or an arbitrary local command), and `specky install-git-hook` makes every future commit write a short AI-generated summary to `specs/history/<sha8>.md`. Indexing, the HTML viewer, and chat land in Phases 3–4.

## Installing on a repo (Phase 1 + 2 workflow)

```bash
cd /path/to/your/repo
uv run --project /path/to/specky specky init               # choose/configure an AI provider
uv run --project /path/to/specky specky install-git-hook    # every future commit gets a doc
```

After that, commit as usual — a summary lands in `specs/history/<sha8>.md` automatically, generated by whichever agent (or none) made the commit.

## Prerequisites

- Python 3.11+
- [`uv`](https://docs.astral.sh/uv/)

## Local install (Claude Code)

```bash
claude plugin marketplace add /path/to/specky
claude plugin install specky
```

## Development

```bash
uv run --project . specky-mcp   # run the MCP server directly, for local testing
```

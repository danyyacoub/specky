# specky

A coding-agent plugin that generates and maintains functional documentation *in place*, indexes it and commit history in SQLite, and renders a searchable HTML viewer with an AI chat for non-technical stakeholders.

Works as a Claude Code plugin (first-class) and via a shared `SKILL.md` + MCP config with opencode and Kiro.

See [specs/PRODUCT.md](specs/PRODUCT.md), [specs/MODULES.md](specs/MODULES.md), and [specs/GLOSSARY.md](specs/GLOSSARY.md) for what this plugin is; see the plan for the phased build order.

## Status

Phase 2 done. Plugin manifest, `document-domain` skill, and a placeholder MCP server (`ping`) are in place (Phase 1). AI provider setup and automatic per-commit micro-docs are in place (Phase 2): `specky init` configures a provider (Anthropic, an OpenAI-compatible endpoint, or an arbitrary local command — including the native `claude` CLI in print mode, if you don't want to set up a separate API key), and `specky install-git-hook` makes every future commit write a short AI-generated summary to `specs/history/<sha8>.md`. `specky sync` backfills any commit that doesn't have one yet — existing history, or one the hook missed. Indexing, the HTML viewer, and chat land in Phases 3–4.

## Installing on a repo (Phase 1 + 2 workflow)

The git hook runs `specky` from a plain shell, so it needs to be on your PATH globally — not just inside this project's own `.venv`:

```bash
uv tool install --editable /path/to/specky   # once published: uv tool install specky
```

Then, in the repo you want documented:

```bash
cd /path/to/your/repo
specky init               # choose/configure an AI provider
specky install-git-hook   # every future commit gets a doc
specky sync                # backfill docs for existing commits
```

After that, commit as usual — a summary lands in `specs/history/<sha8>.md` automatically, generated by whichever agent (or none) made the commit. Run `specky sync` any time to catch up on commits the hook missed (e.g. before `specky` was on PATH).

## Prerequisites

- Python 3.11+
- [`uv`](https://docs.astral.sh/uv/)

## Local install (Claude Code)

```bash
claude plugin marketplace add /path/to/specky
claude plugin install specky
```
